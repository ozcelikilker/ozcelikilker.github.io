## Course Overview

This class will help students to develop the necessary skills to realize threats on a computer network, to decide ways to address these threats, and to design network systems while keeping security in mind.

### Course Objectives

* Students will learn how to perform network security experiments in a controlled environment.
* Students will learn how to analyze and interpret obtained data.
* Students will develop skills to come up with innovative solutions for problems they encounter.

### Learning Outcomes

* Students can explain fundamental network and information security concepts.
* Students can realize and explain threats against Confidentiality, Integrity, and Availability on the network.
* Students can list possible solution techniques & ideas against these threats.
* Students can monitor and manipulate network traffic by using available tools and/or tools they have developed.
